IMPORTANT ABOUT EMAIL / WHATSAPP
--------------------------------
A public static GitHub Pages site cannot silently send email or WhatsApp API
messages by itself. V14 therefore creates:
- WhatsApp links for immediate customer communication.
- mailto: drafts for the configured admin email.
True automatic email and WhatsApp Business API delivery requires an external
provider/backend and credentials; it is not faked in this version.

PUBLIC DEPLOYMENT
-----------------
The demo admin username/password is client-side and therefore NOT secure for
real production use. Before accepting real bookings, use Supabase Auth or a
server-side authentication layer, configure Row Level Security, and remove
the demo credentials.
