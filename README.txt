# Jagdambaa Tours & Travels — V12

V12 adds:
- booking approval workflow
- approve/reject actions
- quotation/advance workflow
- customer booking status page
- mobile/laptop admin access
- shared cloud status through Supabase
- customer WhatsApp notification links
- real UPI QR retained
- status timeline

Workflow:
Enquiry → Quoted/Advance Pending → Confirmed → Completed
or
Enquiry → Cancelled

V12 does NOT pretend to have automated email/WhatsApp APIs configured. Those require provider credentials and setup.

See V12-SETUP-GUIDE.md.
